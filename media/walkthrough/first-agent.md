# Run your first agent

**With GitHub Copilot Chat (VS Code):** open the Copilot Chat panel
(`Ctrl+Shift+I` / `Cmd+Shift+I`) and mention **`@oz`** to invoke the
OzBridge chat participant.

Try one of these starter prompts:

- `@oz /history`
- `@oz /run summarise this file`
- `@oz /cloud generate release notes for the latest commits`

`@oz` streams output back into the chat while the Oz CLI executes
the agent. Each run appears in the **Runs & Resources** view so you
can open, re-play or hand it off to the Warp desktop app.

**Without Copilot (Cursor, Windsurf, VSCodium, …):** the `@oz`
participant needs GitHub Copilot Chat and is VS Code-only. Use OzBridge
over MCP instead — see the
[Quick start](https://github.com/sena-labs/OzBridge#quick-start) for a
one-line stdio setup for your editor or agent.
