# Run your first agent

Open a Copilot Chat view and mention **`@warp`** to invoke the Warp
Bridge chat participant.

Try one of these starter prompts:

- `@warp list my recent runs`
- `@warp /run summarise this file`
- `@warp /cloud generate release notes for the latest commits`

`@warp` streams output back into the chat while the Oz CLI executes
the agent. Each run appears in the **Warp Runs** view so you can open,
re-play or hand it off to the Warp desktop app.
