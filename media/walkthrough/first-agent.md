# Run your first agent

Open a Copilot Chat view and mention **`@oz`** to invoke the OzBridge
chat participant.

Try one of these starter prompts:

- `@oz list my recent runs`
- `@oz /run summarise this file`
- `@oz /cloud generate release notes for the latest commits`

`@oz` streams output back into the chat while the Oz CLI executes
the agent. Each run appears in the **Runs & Resources** view so you
can open, re-play or hand it off to the Warp desktop app.
