6

Tutti i comandi disponibili

/run

Esegui un agente AI localmente nel tuo workspace.

@oz /run refactora questa funzione
/cloud

Esegui un agente nel cloud (consuma crediti).

@oz /cloud deploy to staging
/status

Controlla lo stato delle esecuzioni recenti.

@oz /status run-a7f3
/schedule

Crea e gestisci esecuzioni pianificate (cron).

@oz /schedule list
/models

Elenca i modelli AI disponibili.

@oz /models
/mcp

Elenca i server MCP configurati.

@oz /mcp
/config

Mostra la configurazione attuale e lo stato del CLI.

@oz /config
/init

Genera i file Skills e Rules nel workspace.

@oz /init

Sotto-comandi di /schedule

list

Mostra tutte le pianificazioni.

@oz /schedule list
create

Crea una nuova pianificazione con cron.

@oz /schedule create lint "0 9 * * *" "Esegui lint"
pause / unpause

Metti in pausa o riprendi una pianificazione.

@oz /schedule pause sched-123
delete

Elimina una pianificazione.

@oz /schedule delete sched-123

Personalizza le impostazioni

Apri le impostazioni di VS Code (Ctrl+,) e cerca ozBridge.

⚙️
GIF: Apertura impostazioni di VS Code e modifica dei parametri OzBridge
GIF · 16:9
Impostazione Default Descrizione
ozPath oz Percorso del CLI Oz. Cambia solo se non è nel PATH.
defaultModel auto Modello AI predefinito. auto = Warp sceglie il migliore.
defaultProfile Default Profilo agente da usare.
defaultEnvironment (vuoto) Ambiente cloud predefinito per /cloud.
timeoutMs 300000 Timeout per esecuzioni locali (5 minuti). Aumentalo per task lunghi.
cloudPollingIntervalMs 5000 Intervallo di polling per task cloud (ms).
cloudPollingTimeoutMs 1800000 Timeout massimo di attesa per task cloud (30 min).
maxOutputChars 5000 Lunghezza massima dell'output in chat. Aumenta se risposte troncate.

Scenari comuni

⏱️

L'agente va in timeout

Imposta ozBridge.timeoutMs a 600000 (10 min) o più.

🧠

Vuoi usare un modello specifico

Imposta ozBridge.defaultModel a gpt-4o, claude-sonnet, ecc.

✂️

La risposta viene troncata

Aumenta ozBridge.maxOutputChars a 10000 o più.

9

Risoluzione dei problemi comuni

❌ Il CLI Oz non viene trovato ▼

Sintomo: @oz /config mostra «❌ Non disponibile».

Soluzioni:

1. Verifica che Warp sia installato — apri un terminale e digita where oz (Windows) o which oz (macOS/Linux).

2. Se il comando non viene trovato, vai in Impostazioni → ozBridge.ozPath e inserisci il percorso completo di Oz.

3. Dopo la modifica, ricarica VS Code: Ctrl+Shift+P → Reload Window.

🔑 Errore di autenticazione ▼

Apri un terminale ed esegui oz auth login. Si aprirà il browser per riautenticarti. Dopo il login, torna su VS Code e riprova.

⏱️ L'agente va in timeout ▼

Aumenta il timeout nelle impostazioni:

• Esecuzioni locali: ozBridge.timeoutMs (default 300 000 ms = 5 min)

• Esecuzioni cloud: ozBridge.cloudPollingTimeoutMs (default 1 800 000 ms = 30 min)

• Per operazioni molto pesanti, usa /cloud al posto di /run.

💬 La chat non mostra @oz ▼

1. Verifica che GitHub Copilot Chat sia installato e attivo.

2. VS Code deve essere versione ≥ 1.96.0.

3. Ricarica la finestra: Ctrl+Shift+P → Reload Window.

4. Controlla che l'estensione OzBridge sia abilitata: Ctrl+Shift+X → cerca "OzBridge".

✂️ L'output nella chat è troncato ▼

Aumenta ozBridge.maxOutputChars nelle impostazioni (default: 5000). Prova con 10000 o 20000.

Glossario

Agente
Un programma AI che esegue compiti sul tuo codice (analisi, scrittura, review, test…).
CLI
Command Line Interface — un programma che si usa da terminale. Oz è il CLI di Warp.
Chat Participant
Un'estensione VS Code che risponde nella chat di Copilot con un nome come @oz.
Cloud run
Un'esecuzione dell'agente sui server di Warp (consuma crediti).
Local run
Un'esecuzione dell'agente sul tuo computer (gratuita).
MCP
Model Context Protocol — standard per collegare server di contesto ai modelli AI.
Oz
Il CLI incluso in Warp per controllare agenti, modelli, schedules e integrazioni.
Prompt
Il testo che scrivi nella chat per dire all'agente cosa fare.
Skills
File .md che descrivono le competenze di ogni agente nella pipeline a 7 fasi.
Slash command
Un comando preceduto da / nella chat (es. /run, /cloud).
VSIX
Il formato di pacchetto delle estensioni VS Code (come un file .zip speciale).
Workspace
La cartella del progetto attualmente aperta in VS Code.
